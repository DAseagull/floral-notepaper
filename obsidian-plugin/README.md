# 花笺桌面便签 for Obsidian

花笺桌面便签 1.0.0 是 Windows 上的 Obsidian 本地插件。便签以当前仓库里的 Markdown 为正文，快捷编辑、浮动置顶和截图贴屏都由 Obsidian 提供。主窗口可以最小化，退出 Obsidian 时浮窗和快捷键会释放。最低 Obsidian 版本为 1.15.1。

## 安装和使用

在这个分支的 GitHub 页面选择 **Code → Download ZIP**。解压后，把 `obsidian-plugin/plugin` 中的六个文件复制到目标仓库的 `.obsidian/plugins/floral-desk/`，确认 `manifest.json` 直接位于 `floral-desk` 中。重开仓库，在「设置 → 社区插件」启用「花笺桌面便签」。

| 操作 | 方法 |
|---|---|
| 快捷记录 | `Ctrl+Space` 呼出，正文自动保存到当前仓库的 `笔记/便签`。 |
| 钉到屏幕 | 在快捷窗口点「置顶」，或右键已有 Markdown 选「钉到屏幕」。 |
| 折叠 | 点置顶便签的箭头缩成标题条，点标题恢复尺寸。每次打开默认展开。 |
| 调透明度 | 点 `◐`，快捷窗、浮窗默认值和单张便签可分别设置。100% 只隐藏背景。 |
| 截图贴屏 | `Win+Shift+S` 截图后按 `Ctrl+Alt+V`。可拖动、滚轮缩放、复制、另存 PNG。 |

设置页会显示实际注册的快捷键。默认组合冲突时会尝试 `Ctrl+Alt+Space` 和 `Ctrl+Alt+Shift+V`。同时打开多库时，给各库用不同的全局组合，或在副库清空两项全局键并点「应用」，改用 `Ctrl+P` 中的插件命令。每个仓库独立安装，便签和设置留在各自仓库。

## 设计与维护

- `plugin/main.js` 管理 Obsidian 命令、全局键、剪贴板和 Electron 浮窗。记录通过 Vault API 写入当前库，检测到同时编辑时把浮窗内容另存为恢复便签。`data.json` 保存在各库的插件目录，用于设置和单张透明度。
- `plugin/preload.js` 在插件与沙盒窗口之间传递操作。`window.html`、`window.js`、`styles.css` 实现编辑、预览和控件。透明度作用于背景层。折叠会改变原生窗口的尺寸，展开会按当前屏幕工作区恢复。
- 贴图只在调用时读取剪贴板，临时图片放在内存中，关闭时释放。用户主动另存才写入 PNG。窗口按需启动。浮窗可预览常见 Markdown 和库内位图，完整编辑可从「在库中打开」进入。
- 更新插件时替换这六个文件，保留目标库的 `data.json`。停用插件后，Markdown 依然可读。插件使用 Obsidian 提供的 Electron 桌面接口，升级 Obsidian 后应复测全局键、主窗口最小化后的置顶、背景透明和折叠恢复。

## 验证记录

已在 Windows 上用 Obsidian 1.15.1 / Electron 43.8.9 验证快捷呼出、中文保存、并发修改保护、完全透明、原生折叠、贴图拖动缩放、复制、PNG 写入和关闭后的资源释放。长期使用和混合 DPI 多屏仍需复测。`qa/runtime.js` 是供隔离库使用的测试脚本，会创建测试笔记和图片，应在空白测试仓库中运行。
